# API Tests: Heroes & Animals

Учебный проект автоматизации API-тестирования: Java, RestAssured, JUnit 5, Allure.

Тесты гоняются против локального [json-server](https://github.com/typicode/json-server) —
собственного мок-бэкенда с моделями супергероев и животных. Такой подход даёт полный
контроль над тестовыми данными и стабильные, неflaky прогоны — в отличие от публичных
учебных стендов с общими данными на всех пользователей.

## Стек

- Java 17
- RestAssured 5.5
- JUnit 5
- AssertJ
- Allure 2.29
- Lombok
- json-server (тестовый бэкенд)
- GitHub Actions (CI)

## Структура проекта

```
src/test/java
├── client      — API-клиенты (HeroClient, AnimalClient)
├── config      — конфигурация окружения и спецификации запросов
├── models      — модели данных (Hero, Animal)
├── testdata    — фабрики тестовых данных
└── tests       — тестовые классы
```

## Что покрыто тестами

**Heroes API**
- создание героя и проверка по id;
- создание героя с разными наборами данных (параметризованный тест);
- герой появляется в общем списке;
- обновление героя;
- удаление героя;
- запрос несуществующего героя (негативный кейс).

**Animals API**
- количество животных в списке;
- соответствие типа и имени у каждого животного;
- получение животного по имени.

## Запуск локально

**1. Поднять тестовый бэкенд**

Нужен Node.js. Затем:
```bash
npm install -g json-server
json-server --watch db.json --port 3000
```
Сервер должен остаться запущенным на время прогона тестов. Проверить: `http://localhost:3000/superheroes` — должен вернуть JSON-массив.

**2. Запустить тесты**

В отдельном терминале, в корне проекта:
```bash
mvn clean test
```

**3. Собрать и открыть Allure-отчёт**
```bash
mvn allure:serve
```
Команда сама поднимет сервер и откроет отчёт в браузере.

## Кастомный URL бэкенда

По умолчанию тесты идут на `http://localhost:3000`. Переопределить можно системными свойствами:
```bash
mvn test -Dbase.url=http://другой-хост/superheroes -Danimal.url=http://другой-хост/animal
```

## CI

При пуше в `master` GitHub Actions:
1. поднимает json-server как тестовое окружение;
2. прогоняет `mvn clean test`;
3. собирает Allure-отчёт и публикует его на GitHub Pages, даже если часть тестов упала.

Актуальный отчёт: `https://FreePoet63.github.io/APIRestAssured/`

## Известные особенности

- Создание героя (`POST /superheroes`) возвращает `201`, тело содержит сгенерированный сервером `id` (строка).
- `GET /animal` возвращает плоский массив, без обёртки.
